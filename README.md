# nicolas-schtickzelle.net — Wix-free rebuild, English + French

A complete, self-contained rebuild of <https://www.nicolas-schtickzelle.net/> and its
French version as a [Quarto](https://quarto.org) website. No Wix, no proprietary
editor, no vendor lock-in: every page is a plain text file you (or Claude) can edit,
and every image lives in this folder.

English is at the root, French under `/fr/`, with an EN/FR toggle in the navigation
bar.

---

## Look at it right now

The site is already built. Open this file in your browser:

```
_site/index.html
```

Double-click it in File Explorer, or drag it onto a Chrome/Edge window. Everything
works offline — both languages, images, navigation, search.

## Edit and rebuild

You need Quarto once: <https://quarto.org/docs/get-started/>. If you use RStudio you
almost certainly have it already (`quarto --version` in a terminal to check).

```powershell
cd "D:\OneDrive - UCL\CV et al\Wix website\Copy by Claude"
python tools\build_site.py    # rebuild everything, both languages
```

That one command regenerates the publication list, regenerates the French pages, and
renders both sites. While drafting, `quarto preview` in this folder gives you a
live-reloading English preview (it does not cover `/fr/`).

## How the two languages work

**English is the single source of truth.** You never edit the French pages — they are
generated.

```
index.qmd  (English, you edit this)
        +
data/translations.fr.json  (French wording, you or Claude edit this)
        |
        v  python tools/build_french.py
fr/index.qmd  (GENERATED — do not edit)
```

`tools/build_french.py` walks each English page, chops it into "runs" of prose, and
swaps each run for its French equivalent, leaving all structure (layout blocks,
images, links) untouched. Every run has a stable id like `mentoring.qmd#17`, and the
memory stores the English text alongside the French.

That last detail is what makes the workflow work. When you edit an English paragraph,
its stored English no longer matches, so the pair is flagged **stale** and that block
falls back to English rather than silently showing an out-of-date translation.

```powershell
python tools\build_french.py --status   # what is missing or stale
python tools\build_french.py --dump     # every run and its id
python tools\rekey_translations.py      # after adding/removing English paragraphs:
                                        # re-attach French texts, list what needs translating
```

**Your routine:** edit the English, run `--status`, then ask Claude in Cowork to
"update the French". Claude reads the status, translates only the flagged blocks,
updates `data/translations.fr.json`, and rebuilds. Nothing else gets re-translated, so
your existing wording is never churned.

French navigation labels live in `fr/_quarto.yml` and are hand-maintained — they
change about once a decade.

The French seed came from your own Wix French pages, so the voice and terminology
(*vulgarisation*, *mentorat*, *mémorant.es*) are yours, not a machine's.

## What is where

| Path | What it is |
|---|---|
| `_quarto.yml` | English site config: navigation bar, footer, page order, metadata |
| `fr/_quarto.yml` | French navigation labels (hand-maintained) |
| `fr/*.qmd` | **Generated** French pages — never edit |
| `data/translations.fr.json` | The French wording, keyed by run id |
| `index.qmd` | Short bio (home page) |
| `research-interests.qmd` | Research interests |
| `publications.qmd` | Publications |
| `mentoring.qmd` | Mentoring |
| `teaching.qmd` | Teaching |
| `outreach.qmd` | Outreach |
| `contact.qmd` | Contact |
| `styles.scss` | All the styling. Colours are the first five lines |
| `assets/img/` | 90 images, downloaded from Wix and resized for the web |
| `assets/files/` | PDFs linked from the Outreach page |
| `data/publications.csv` | Your publication list, as plain data |
| `tools/` | Small maintenance scripts (below) |
| `_includes/` | Auto-generated publication lists — don't edit by hand |
| `_site/` | The built website. Regenerated by `quarto render`; safe to delete |

A `.qmd` file is just Markdown with a header. Writing `## Something` makes a
section heading, `*word*` makes italics, `[text](url)` makes a link. The
`::: cards` / `::: card-ns` blocks you'll see are Quarto's way of wrapping content
in a styled box — copy an existing block to add another mentee or another course.

## The maintenance scripts

All plain Python 3, no libraries needed except Pillow for the image one.

```powershell
python tools\build_site.py            # the one you want: rebuild everything
python tools\build_french.py          # regenerate fr/ only
python tools\build_french.py --status # what needs translating
python tools\build_publications.py    # turn the CSV into the publications page
python tools\update_publications.py   # preview the full list from OpenAlex
python tools\update_publications.py --write   # ...and overwrite data/publications.csv
python tools\download_assets.py       # re-fetch any missing image or PDF from Wix
python tools\optimise_images.py       # resize images for the web (already done)
```

Typical publication update: edit `data/publications.csv` in Excel → run
`build_site.py`. The publication list is shared between both languages.

## Things you should know

**Two Wix apps could not be copied.** The career-milestones timeline on the home
page (*Lumifish Timeline*) and the two full publication tables (*Table Master*) are
third-party Wix apps that keep their content on their own servers, not in your
pages. Nothing of them exists in the HTML that a browser or a crawler receives —
which is a fairly good illustration of why moving off Wix is worth doing.

- The **timeline** is now a native HTML timeline in `index.qmd` with two entries
  I could verify. Add the rest — it's two lines per milestone.
- The **publication list** was rebuilt from [OpenAlex](https://openalex.org) and
  currently holds 31 articles and 7 book chapters, covering roughly 2009 and
  2014–2026. Run `tools/update_publications.py --write` to pull the full record
  (about 105 articles), then prune anything mis-attributed. Please check the entries
  I seeded — OpenAlex occasionally garbles author initials or page numbers.

**Three drifts between your English and French pages,** found while migrating and now
reconciled:

- LBIO1116 was "5 ECTS" in English and "6 ECTS" in French. Both now say 4 ECTS.
- The French research-interests page had one paragraph still in English
  ("In my research group we combine observations…"). Now translated.
- On the English outreach page, the Huffington Post thumbnail linked to the RTL
  article. The French page had the right URL; the English now uses it too.


**The contact form is now an email link.** A static site has no server to receive
form posts. If you want a real form back, Formspree or Web3Forms give you one for
free with a few lines of HTML.

**The map is OpenStreetMap** rather than Google Maps, so it needs no API key. Check
the pin lands on the Carnoy building; the coordinates are in `contact.qmd`.

**Leftover files at the top level.** `contact.html`, `contact_files/`, `site_libs/`
and `.quarto/` are debris from a first build attempt and can be deleted — OneDrive
blocked me from removing them.

## When you want to publish it

The `_site/` folder is the whole website: static files, nothing to install on a
server. Options, cheapest first:

- **GitHub Pages** — free, and `quarto publish gh-pages` does it in one command.
- **Netlify** — free tier, drag `_site/` onto their dashboard, or connect a repo.
- **UCLouvain web hosting** — upload `_site/` by FTP if they offer space.

Your domain `nicolas-schtickzelle.net` can be pointed at any of these; you'd change
the DNS records at whoever sells you the domain, then cancel the Wix plan.
